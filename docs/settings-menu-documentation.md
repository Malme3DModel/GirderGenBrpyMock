# 設定メニュー機能説明書

## 概要
GirderGenBrpyMockアプリケーションの設定メニューは、ユーザーがアプリケーションの動作や表示をカスタマイズできる包括的な設定システムです。上部ツールバーの歯車アイコンからアクセスできます。

## 設定項目一覧

### 1. 一般設定
**目的**: アプリケーションの基本的な動作設定を管理

**主な機能**:
- **LODモード切り替え**: LOD200（簡易表示）とLOD300（詳細表示）の切り替え
- **属性情報表示**: 3Dモデルの属性情報表示のON/OFF切り替え

**使用方法**:
1. 設定メニューから「一般設定」を選択
2. LODモードをラジオボタンで選択
3. 属性情報表示をチェックボックスで切り替え
4. 設定は自動保存されます

**技術詳細**:
- LOD200モードでは簡略化されたサイドメニューが表示
- LOD300モードでは全ての詳細設定項目が利用可能
- 属性情報は3Dモデル上でのマウスオーバー時に表示

---

### 2. 材料強度設定
**目的**: 構造計算に使用する材料強度パラメータの管理

**対象材料**:
- **鋼材**: 主桁用と横桁用（横桁、端横桁、荷重分配横桁）の2種類
- **鉄筋**: D10, D13, D16, D19, D22, D25, D29, D32, D35, D38の各径
- **コンクリート**: 設計基準強度と最大骨材寸法

**主な機能**:
- 材料強度値の編集（Handsontableによる表形式編集）
- 鋼材種別の選択（SS400, SM400A, SM400B, SM490A, SM490B, SM490C, SM520B, SM570）
- 自動値更新（鋼材種別変更時の降伏強度・引張強度自動設定）
- プリセット保存/読込（JSON形式）

**使用方法**:
1. 設定メニューから「材料強度設定」を選択
2. 各材料の強度値を表で編集
3. 鋼材はプルダウンで種別選択可能
4. 「プリセット保存」でJSON形式で設定を保存
5. 「プリセット読込」で保存した設定を復元

**プリセットファイル形式**:
```json
{
  "materialStrength": {
    "steel": {
      "mainGirder": { "type": "SS400", "fy": 235, "fu": 400 },
      "crossBeam": { "type": "SM490A", "fy": 325, "fu": 490 }
    },
    "rebar": { "D10": 345, "D13": 345, ... },
    "concrete": { "fck": 24, "maxAggregateSize": 20 }
  },
  "timestamp": "2024-01-01T00:00:00.000Z",
  "version": "1.0"
}
```

### 3. モデル表示設定
**目的**: 3Dモデルの表示/非表示を部材別に制御

**制御可能部材**:
- 主桁（H形鋼）
- 横桁（H形鋼）
- 端横桁（H形鋼）
- 床版
- 舗装
- 中間支点
- ガセットプレート（3種類）
- L形鋼

**主な機能**:
- 各部材の表示/非表示切り替え（チェックボックス）
- リアルタイム反映（設定変更と同時に3Dモデルに反映）
- 設定の永続化（ページリロード後も設定維持）

**使用方法**:
1. 設定メニューから「モデル表示設定」を選択
2. 表示したい部材にチェック、非表示にしたい部材のチェックを外す
3. 設定は即座に3Dモデルに反映されます

---

### 4. モデル外観設定
**目的**: 3Dモデルの色と透過度を部材別に設定

**設定可能項目**:
- **色設定**: 各部材の表示色をカラーピッカーで選択
- **透過度設定**: 0%（完全不透明）〜100%（完全透明）をスライダーで調整

**対象部材**:
- 主桁、横桁、端横桁、床版、舗装、中間支点、各種ガセットプレート、L形鋼

**主な機能**:
- リアルタイムプレビュー（設定変更と同時に3Dモデルに反映）
- デフォルト値への復元機能
- 設定の永続化

**使用方法**:
1. 設定メニューから「モデル外観設定」を選択
2. 各部材の色をカラーピッカーで選択
3. 透過度をスライダーで調整
4. 設定は即座に3Dモデルに反映されます

**技術詳細**:
- Three.jsのMaterial.colorとMaterial.opacityプロパティを制御
- 透過度設定時は自動的にMaterial.transparentがtrueに設定

---

### 5. メニュー設定
**目的**: サイドメニューの表示順序と表示/非表示を制御

**主な機能**:
- **表示/非表示制御**: 各サイドメニューの表示切り替え（LOD300モードのみ）
- **表示順序変更**: ドラッグ&ドロップによる並び順変更
- **リアルタイム反映**: 設定変更と同時にサイドメニューに反映

**対象メニュー**:
- 主桁、床版、舗装、横構、中間支点、横桁、端横桁、その他、カスタムメニュー

**使用方法**:
1. 設定メニューから「メニュー設定」を選択
2. 表示したいメニューにチェック（LOD300モードのみ）
3. メニュー項目をドラッグ&ドロップで並び替え
4. 設定は即座にサイドメニューに反映されます

**制限事項**:
- 表示/非表示制御はLOD300モードでのみ利用可能
- LOD200モードでは「その他」メニューのみ表示される仕様

---

### 6. カスタムメニュー設定
**目的**: ユーザー独自のサイドメニューを作成・管理

**主な機能**:
- **カスタムメニュー作成**: 既存の入力項目から選択してオリジナルメニューを作成
- **メニュー管理**: 作成、編集、削除、複製機能
- **プリセット機能**: JSON形式での保存/読込
- **入力タイプ対応**: 数値入力とテキスト入力の両方に対応

**使用方法**:
1. 設定メニューから「カスタムメニュー設定」を選択
2. 「新規作成」でカスタムメニューを作成
3. メニュー名を入力
4. 利用可能な入力項目から必要な項目を選択
5. 「保存」で作成完了
6. 作成したメニューはサイドメニューに追加されます

**利用可能な入力項目**:
- **基本情報**: 業務名、路線名、道路種別
- **寸法情報**: 各部材の寸法パラメータ（mm、m単位）
- **位置情報**: 座標、距離標（m、km単位）
- **数量情報**: 本数、列数

**プリセットファイル形式**:
```json
{
  "customMenus": [
    {
      "id": "menu1",
      "name": "基本設定メニュー",
      "items": [
        { "name": "Name_P", "label": "業務名", "unit": "", "inputType": "text" },
        { "name": "L", "label": "橋長", "unit": "m", "inputType": "numeric" }
      ]
    }
  ],
  "timestamp": "2024-01-01T00:00:00.000Z",
  "version": "1.0"
}
```

**技術詳細**:
- Handsontableを使用した表形式編集
- テキスト入力項目は文字列検証、数値入力項目は数値検証を実行
- 単位変換システムと連携し、設定された単位で表示

---

### 7. 単位系設定
**目的**: 入力項目の表示単位を統一的に変更し、内部計算用の単位に自動変換

**対応単位系**:
- **長さ単位**: mm ⇔ m（相互変換可能）
- **距離単位**: m ⇔ km（相互変換可能）
- **その他**: %、本、列、NO.（変換不可、表示のみ）

**主な機能**:
- **単位選択**: プルダウンメニューで表示単位を選択
- **自動変換**: 表示値と内部保存値の自動変換
- **表示精度制御**: m単位は小数点以下3桁、その他は1桁で表示
- **プリセット機能**: 単位設定のJSON保存/読込

**使用方法**:
1. 設定メニューから「単位系設定」を選択
2. 長さ単位（mm/m）と距離単位（m/km）をプルダウンで選択
3. 設定は全ての入力項目に即座に反映されます
4. 「プリセット保存」で設定を保存可能

**変換例**:
- 長さ: 300mm → 0.300m
- 距離: 50000m → 50.000km
- 内部保存: 常にデフォルト単位（mm、m）で保存

**技術詳細**:
- `getDisplayValue()`: 内部値を表示用に変換
- `getStorageValue()`: 表示値を内部保存用に変換
- `getDisplayFormat()`: 単位に応じた数値フォーマットを返す
- 変換係数は`unitConversionFactors`オブジェクトで管理

**プリセットファイル形式**:
```json
{
  "unitSettings": {
    "length": "m",
    "distance": "km"
  },
  "timestamp": "2024-01-01T00:00:00.000Z",
  "version": "1.0"
}
```

## 共通機能

### プリセット機能
多くの設定項目でJSON形式のプリセット保存/読込機能を提供:
- **保存**: 現在の設定をJSONファイルとしてダウンロード
- **読込**: 保存したJSONファイルを選択して設定を復元
- **ファイル名**: 自動的に日付付きファイル名を生成

### リアルタイム反映
設定変更は即座にアプリケーションに反映:
- 3Dモデルの表示更新
- サイドメニューの構成変更
- 入力項目の単位表示変更

### 設定の永続化
全ての設定はブラウザのローカルストレージに保存され、ページリロード後も維持されます。

---

## 使用上の注意

1. **LODモード**: LOD200とLOD300で利用可能な機能が異なります
2. **単位変換**: 内部計算は常にデフォルト単位で実行されます
3. **プリセット**: 異なるバージョン間でのプリセット互換性は保証されません
4. **ブラウザ対応**: モダンブラウザでの使用を推奨します

---

## トラブルシューティング

### よくある問題
1. **設定が保存されない**: ブラウザのローカルストレージが無効になっている可能性
2. **3Dモデルが更新されない**: ページをリロードしてください
3. **プリセット読込エラー**: JSONファイルの形式を確認してください
